# Local SFX library (user curated)

MIMIR never downloads or synthesizes effects. Put your own licensed sounds in category folders:

```
sfx_library/
  transition/        quiet whoosh for the cold open -> main restart
  impact/  reversal/  disbelief/  confusion/  absurdity/  fail/  awkward/  hype/  fear_shock/  wholesome_ironic/
```

At most one accent is used per Short, only on a real expectation break, never in the cold open and
never burying the payoff. Empty folders simply mean "no accent".
